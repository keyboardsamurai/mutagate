# ADR-0021: Copilot boundaries
Status: accepted 2026-11-09
Concern: The native Copilot hook file (`.github/hooks/mutagate.json`) also reaches callers that mutagate does not support. The VS Code Local agent harness reads `.github/hooks` and sends Local payloads that have `hook_event_name` and block on exit 2. The committed file reaches each job of the Copilot cloud coding agent. The Copilot sandbox can make the cache root read-only, so state, locks and workers fail.
Decision: A `--harness copilot` hook call whose payload has `hook_event_name` is a VS Code Local call. It exits 0 and does nothing else: no state, trace, recording or stdout. The spawned `--mutate` handler is not a Local call. A native hook call with `COPILOT_AGENT_PROMPT` or `GITHUB_COPILOT_API_TOKEN` in its environment is a cloud agent call. It exits 0 and does nothing else, unless the config has `copilotCloud: true`; then it runs as a local native call. `SessionStart` and `agentStop` first probe a write to `<cacheRoot>/repos/<hash>/state` and remove the empty dirs that the probe made. When the write fails, `SessionStart` gives `additionalContext` and each `agentStop` gives a progress line, both `mutagate inactive: cannot write <path>`; `postToolUse` takes the silent exception path. mutagate does not start a worker, block, write a marker file or write outside the sandbox there.
Rationale: Local payloads use other output and exit codes, and Copilot is the supported VS Code harness (#35 D21). A cloud job gates a repo whose owners did not choose mutagate for the cloud agent (#35 D22). In a sandbox, the failed cache root is the only state root, so no state can last (#35 D23). The probe removes its dirs, so a repo that mutagate does not use gets no data dir, as with the other harnesses.
Alternatives: Run the cloud agent by default. The committed file reaches every cloud job, so teams that did not choose it get the gate. Rejected. Keep a marker file or a state root outside the sandbox. That is a sandbox escape. Rejected.
Consequences: The cloud markers are UNCONFIRMED until spike S16, which gates the 0.9.2 release. A repo that opts in with `copilotCloud: true` gives the cloud job the mutagate gate. In a Copilot sandbox, mutagate is inactive and says so at each `agentStop`.
