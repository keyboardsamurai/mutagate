# Code of conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Everyone who takes part in issues, pull requests and discussions agrees to follow it.

Report unacceptable behavior to the maintainer, [@keyboardsamurai](https://github.com/keyboardsamurai). For a private report, use a [private advisory](https://github.com/keyboardsamurai/mutagate/security/advisories/new) and name it "Code of conduct". For a public matter, open an issue. The maintainer reviews each report and keeps the reporter's identity private.
